## Cómo leer esta tabla

Cada fila dice en qué gama (baja, media, alta o premium) está un modelo de procesador o de placa de video. El criterio es el de `gamas.md`: la gama baja usa Celeron, Pentium, Core i3 o Ryzen 3; la media, Core i5 o Ryzen 5; la alta, Core i7, Core i9, Ryzen 7 o Ryzen 9; la premium, Core Ultra 9 o Ryzen 9 9900X / 9950X. Solo cuentan los procesadores de plataformas actuales (AM4, AM5, LGA1200, LGA1700, LGA1851). Placas de video: gama media GTX 1650, RTX 3050, RX 580, RX 7600 o RTX 5050; alta RTX 5060, RTX 5060 Ti o RTX 5070; premium RTX 5070 o RTX 5070 Ti. La gama baja no lleva placa de video.

El asistente usa esta tabla para filtrar productos por gama y para ubicar los requisitos de un juego o programa en una gama. Un modelo que no está en la tabla no tiene gama: el asistente lo dice y no la adivina.
